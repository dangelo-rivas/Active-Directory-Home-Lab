# 06 - Active Directory Troubleshooting

## Overview

This section documents controlled, simulated support incidents in the ACME Corporation Windows domain. Each exercise follows the same incident workflow: identify the reported symptom, reproduce and investigate it, confirm the root cause, perform an authorized fix, and verify the outcome.

## Lab Environment

| Component | Configuration |
|---|---|
| Domain | `ad.acme.test` (`ACME`) |
| Domain controller | `ACME-DC01` — Windows Server 2025 |
| Workstation | `ACME-PC-001` — Windows 11 Pro |
| Directory administration | Active Directory Users and Computers (ADUC) |
